# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Send a
minimal reproduction, affected contract and function, compiler/package
versions, and any relevant transaction or test evidence to
[support@isogate.tech](mailto:support@isogate.tech).

Do not include private keys, credentials, personal data, or undisclosed
production details in an initial report. We will acknowledge a report when
possible and coordinate a fix or public disclosure with the reporter.

## Important limitations

This is public source code, not an audit or a security guarantee. The included
local tests use synthetic dependencies and do not prove safety on a live
network. Never send funds to an address solely because it appears in this
repository; independently verify the chain, bytecode, source match, and
administrative configuration.
